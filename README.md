🕹️ Java Pacman Game
A faithful, object-oriented implementation of the classic Pacman arcade game, built from scratch in Java. This project is designed with a strong focus on clean code architecture, modular design, and efficient real-time rendering using Java Swing.

✨ Key Features
Classic Arcade Mechanics: Navigate the maze, collect dots and power pellets, avoid ghosts, and rack up your high score.

Object-Oriented Architecture: Built using solid OOP principles (inheritance, encapsulation, and polymorphism) to cleanly separate game entities (Pacman, Ghosts, Walls, Dots) from the core engine.

Custom Rendering & Game Loop: Utilizes Java Swing and double-buffering techniques to ensure smooth frame updates and responsive keyboard input handling.

Collision Detection: Precise grid-based and bounding-box collision detection for walls, collectibles, and entity interactions.

Ghost Behavior & State Management: Implements directional movement logic and state handling for standard chase/scatter mechanics and power pellet vulnerabilities.

🛠️ Tech Stack & Concepts
Language: Java (JDK 8+)

GUI Framework: Java Swing (JPanel, Graphics2D)

Core Concepts:

Game Loop & Multi-threading

Event Listeners (Keyboard controls)

2D Array Grid Mapping

🚀 Getting Started
Prerequisites
Ensure you have the Java Development Kit (JDK 8 or higher) installed on your machine.
